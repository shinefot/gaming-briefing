# Gaming Industry Briefing

An automated daily briefing on the gaming industry — financials, community activity, and regulatory filings — generated by a scheduled pipeline and committed back to this repo as dated Markdown. Runs itself every morning on GitHub Actions.

**See the latest briefings in [`/briefings`](./briefings).** A new one is generated and committed automatically each day.

## What it does

Every morning, with no human involvement, the pipeline:

1. **Collects** three independent signals on ~12 major gaming companies — Steam concurrent players, latest stock prices, and recent SEC filings.
2. **Stores** them in a committed SQLite database, building a time-series whose git history *is* the dataset.
3. **Writes** a concise briefing with an LLM that leads with what *changed* (e.g. "Capcom surges +67% in concurrent players") and commits it to the repo.

## How it's built

The system is split into two planes:

- **Data plane** — deterministic code that fetches, normalizes, and stores facts. No LLM. Either it returns data or throws a clear error, so it's testable and easy to operate. Every source fails gracefully: one dead feed produces a smaller result, never a crashed run.
- **Reasoning plane** — the only place an LLM is used. It is handed exact figures pulled from the database by plain code and asked only to *phrase* them — never to recall or invent numbers. The prompt also forbids speculation about causes and superlatives the data can't support ("lowest in this list" is allowed; "historic low" is not), keeping the output grounded.

Everything flows through one normalized schema (`Doc` for text, `Metric` for time-series), so new sources can be added without touching the reasoning code.

## The three sources

| Section | Source | What it demonstrates |
|---|---|---|
| Market & Financials | SEC EDGAR + Finnhub | structured, authoritative data |
| Community & Engagement | Steam Web API | a self-built time-series that doesn't exist off the shelf |
| Regulatory Filings | SEC EDGAR | parsing official disclosures |

## Stack

- **Scheduler & runtime:** GitHub Actions (`cron`) — no server.
- **Storage:** SQLite committed to the repo; its git history is the dataset.
- **LLM:** Anthropic Claude (Haiku) for the daily write-up.
- **Cost:** infrastructure is free; LLM usage is a few cents per month.

## Run it locally

```bash
pip install -r requirements.txt
cp .env.example .env        # then add your FINNHUB_API_KEY and ANTHROPIC_API_KEY
python run.py               # collect data + write today's brief
python show.py              # quick text dashboard of stored data
python -m pytest            # run the tests
```
