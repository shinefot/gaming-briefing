# Gaming Industry Briefing

An automated daily briefing on the gaming industry — financials, community
activity, and release news — generated by a scheduled pipeline and committed
back to this repo as dated Markdown. Built to run entirely on free tiers.

> **Status: in progress.** The data-plane spine and the Steam (community)
> lane are working. Financials, news, and the reasoning/synthesis plane are
> next. See _Roadmap_ below.

## Why it's built this way

The system is split into two planes:

- **Data plane** — boring, deterministic code that fetches, normalizes, and
  stores facts on a timer. No LLM involved. Either it returns data or it
  throws a clear error, so it's testable and easy to operate.
- **Reasoning plane** — the only place an LLM is used: clustering duplicate
  stories, classifying rumor vs. official, and writing the briefing from data
  the data plane already fetched (so it phrases numbers, never recalls them).

Everything flows through one normalized schema (`Doc` for text, `Metric` for
time-series), which means new sources can be added without touching the
reasoning code.

## The three-section slice

| Section | Source | Competency it demonstrates |
|---|---|---|
| Market & Financials | SEC EDGAR + a stock API | structured, authoritative data |
| Community & Hype | Steam Web API | building a dataset that doesn't exist off the shelf |
| Release & News | RSS + search | clustering messy text, rumor-vs-official classification |

## Infrastructure (free-tier by design)

- **Scheduler & runtime:** GitHub Actions (`cron`) — no server to pay for.
- **Storage:** SQLite committed to the repo. Its git history *is* the
  time-series dataset and the proof the pipeline ran. It can't be backfilled,
  so the Steam lane was built first.
- **Resilience:** every source fails gracefully — one feed being down produces
  a "data unavailable" note, never a crashed run.

## Run it

```bash
pip install -r requirements.txt
python run.py          # runs the data plane (Steam lane today)
python -m pytest       # run the tests
```

## Deliberately out of scope (future work)

Social-media firehose (rate-limit fragility on free tiers), YouTube trailer
vision, a web dashboard, and human-in-the-loop review. Each is a known next
step, not a pretended feature.
